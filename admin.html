How publishing works on GitHub Pages

This is a static-site editor. It can save drafts in your browser with localStorage, export JSON, and help you update content without touching layout code. For public changes, replace the data in content.js, commit to main, and GitHub Pages will serve the updated site.

Because GitHub Pages is static, there is no server-side password authentication or private file upload endpoint in this version. Do not store secrets here.

Content JSON Editor

Edit projects, publications, media paths, CV path, profile text, education, experience, skills, and awards. Save Draft stores only in this browser; Export JSON creates a file you can use to update content.js.
